# 끝말잇기 배틀 기획서

> 최종 업데이트: 2026-08-07

## 프로젝트 개요

끝말잇기와 가비지 공격을 결합한 LAN 1:1 실시간 대전 미니게임이다. 두 플레이어는 각자의 독립 체인을 이어 게이지를 채우고, 상대에게 강제 시작 글자와 HP 피해를 보낸다. 단어 판정과 매치 상태는 서버가 권위적으로 관리한다.

## 기술 스택

| 항목 | 기술 |
|---|---|
| 런타임 | Node.js 18+, ES Modules |
| 서버 | `node:http`, `ws` WebSocket |
| 클라이언트 | 바닐라 JavaScript, HTML5, CSS3 |
| 데이터 | 번들 JSON 사전, 메모리 `Set` 조회 |
| 테스트 | Playwright |

## 아키텍처

### 디렉토리 구조

```text
wordchain-battle/
├─ assets/             # 런처용 키 아트
├─ data/               # 런타임 단어 사전
├─ docs/               # 현재 상태와 변경 이력
├─ public/             # 브라우저 UI와 클라이언트 모듈
├─ scripts/            # 단어 사전 빌드 도구
├─ tests/              # Playwright 회귀 테스트와 승인 캡처
├─ game.js             # 순수 게임 규칙과 상태 전이
├─ server.js           # HTTP/WebSocket 서버와 런처 어댑터
└─ words.js            # 사전 조회, 두음법칙, 가비지 후보
```

### 핵심 모듈

| 모듈 | 파일 | 역할 |
|---|---|---|
| 서버 진입점 | `server.js` | 2인 접속, 양쪽 JOIN 게이트, 카운트다운, 타이머, 메시지 중계, 독립/런처 실행 |
| 게임 규칙 | `game.js` | HP·게이지·독립 체인·가비지·승패·리매치 상태 관리 |
| 단어 규칙 | `words.js` | 한글 명사 검증, 정방향 두음법칙, 가비지 음절 후보 생성 |
| 클라이언트 제어 | `public/js/main.js` | 서버 이벤트를 UI 상태 전이와 입력 동작에 연결 |
| 화면 렌더링 | `public/js/ui.js` | HP·게이지·체인·타이머·알림·결과 화면 렌더링 |
| 네트워크 | `public/js/network.js` | WebSocket 연결과 이벤트 디스패치 |
| 입력 검증 | `public/js/input.js` | 한글 입력 확인과 거절 사유 문구 변환 |

## 알려진 제약사항

- AI 상대는 제공하지 않으며 두 명의 WebSocket 클라이언트가 필요하다.
- 단어 사전은 서버 시작 시 메모리에 적재되며 실행 중 외부 사전과 동기화하지 않는다.
- 게임은 단일 2인 방을 관리하며 다중 방 매칭은 지원하지 않는다.
- 사용자 노출 UI는 한국어 단일 언어다.

## 향후 계획

- AI 상대 및 다중 방 지원은 현재 범위 밖이다.
