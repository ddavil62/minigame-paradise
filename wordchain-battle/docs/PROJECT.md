# 끝말잇기 배틀 기획서

> 최종 업데이트: 2026-08-07

## 프로젝트 개요

끝말잇기와 가비지 공격을 결합한 LAN 1:1 실시간 대전 미니게임이다. 두 플레이어는 각자의 독립 체인을 이어 게이지를 채우고, 상대에게 강제 시작 글자와 HP 피해를 보낸다. 단어 판정과 매치 상태는 서버가 권위적으로 관리한다.

## 기술 스택

| 항목 | 기술 |
|---|---|
| 런타임 | Node.js 18+, ES Modules |
| 서버 | `node:http`, `ws` WebSocket |
| 클라이언트 | 바닐라 JavaScript, HTML5, CSS3 |
| 데이터 | 번들 JSON 사전, 메모리 `Set` 조회 |
| 테스트 | Playwright |

## 아키텍처

### 디렉토리 구조

```text
wordchain-battle/
├─ assets/             # 런처용 키 아트
├─ data/               # 런타임 단어 사전
├─ docs/               # 현재 상태와 변경 이력
├─ public/             # 브라우저 UI와 클라이언트 모듈
├─ scripts/            # 단어 사전 빌드 도구
├─ tests/              # Playwright 회귀 테스트와 승인 캡처
├─ ai.js               # 난수 주입 가능한 순수 보통 AI 단어 선택기
├─ bot.js              # 서버 관리형 WebSocket AI 클라이언트
├─ game.js             # 순수 게임 규칙과 상태 전이
├─ server.js           # HTTP/WebSocket 서버와 런처 어댑터
└─ words.js            # 사전 조회, 두음법칙, 가비지 후보
```

### 핵심 모듈

| 모듈 | 파일 | 역할 |
|---|---|---|
| 서버 진입점 | `server.js` | 2인 접속, JOIN 게이트, 카운트다운, 타이머, 서버 관리형 AI 인증·생명주기, 독립/런처 실행 |

## 알려진 제약사항

- AI 난이도는 보통 한 종류이며 학습형 AI·전적·AI 전용 보상은 제공하지 않는다.
- 단어 사전은 서버 시작 시 메모리에 적재되며 실행 중 외부 사전과 동기화하지 않는다.
- 게임은 단일 2인 방을 관리하며 다중 방 매칭은 지원하지 않는다.
- 사용자 노출 UI는 한국어 단일 언어다.

## 서버 안전성 및 이벤트 의미

- 카운트다운은 timeout 취소와 세대 번호, 게임 객체 및 접속 플레이어 identity 검증을 함께 사용한다. 재접속이나 리매치로 교체된 게임에는 이전 예약 콜백이 영향을 주지 않는다.
- 정적 파일은 URL을 한 번 디코딩한 뒤 `..`, 역슬래시, NUL을 거부하고 `path.relative()`로 `public/` 또는 `assets/` 루트 내부인지 확인한다.
- `WORD_ACCEPTED.wasGarbage`는 제출자가 직전에 받은 강제 글자에 대응한 단어임을 뜻한다. `garbagedOpponent`는 해당 제출로 상대에게 새 가비지를 발사했는지 뜻하므로 두 필드는 독립적이다.
