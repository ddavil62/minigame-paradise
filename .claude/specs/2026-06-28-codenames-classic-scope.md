# Scope: 코드네임 클래식 (정통 4인 팀 대전) — 11번째 신규 게임

[목적유형: feature / visual_change: ui / pipeline: full / clarity: high, grilled: false]

## 핵심 목적

정통 Codenames(25단어, 단일 공유 키, 선공팀 9/후공팀 8/중립 7/암살자 1, 스파이마스터-요원 역할 시야 분리, 2팀 턴제 경쟁, 암살자 즉시 패배)를 11번째 게임 "코드네임"으로 추가. 기존 codenames-duet(2인 협력)과 독립 병존. 이번은 휴먼 전용 4인(2:2), 향후 봇 삽입 가능한 슬롯 구조 유지.

## 확정 방향

1. 정통 룰 신규 게임, codenames-duet과 독립 병존 (`/codenames-duet/` vs `/codenames/`)
2. 2:2 = 2팀(레드/블루) × [스파이마스터 1 + 요원 1] 역할 구성
3. 휴먼 전용 — AI 봇은 이번 작업에서 제외, 단 아키텍처는 봇 확장 여지 유지
4. codenames-duet 인프라 재활용(보드 구조/단어팩/단서 UI 패턴), 키 구조·역할 시야·팀 턴·경쟁 승패는 신규 구현

## 캐논 기본값 (정통 Codenames 표준)

- **선공**: 9장 보유 팀이 선공. 어느 팀(레드/블루)이 9장인지는 매 게임 랜덤. 보드에 팀별 잔여 카드 수 표시.
- **추측 횟수**: 힌트 숫자 + 1까지 추측 가능(정통 보너스). 요원은 언제든 조기 패스(턴 종료) 가능.
- **턴 종료 규칙**:
  - 자기 팀 카드 적중 → 계속 추측(한도 내)
  - 중립 카드 → 즉시 턴 종료
  - 상대 팀 카드 → 상대 진척 +1 + 즉시 턴 종료
  - 암살자 → 선택 팀 즉시 패배(상대 승리)
  - 한도 소진 또는 패스 → 턴 종료
- **승리**: 자기 팀 색 카드 전부 공개(선공 9 / 후공 8) → 해당 팀 승리
- **로비 팀·역할 배정**: 4인이 팀(레드/블루) + 역할(스파이마스터/요원) 자유 선택. 각 팀에 스파이마스터 1 + 요원 1이 모두 채워지면 호스트가 시작. 중복 방지 가드.
- **리매치**: 게임 종료 후 "한 판 더" (omok REMATCH 패턴 참고), 선공 팀 교체 + 보드 재생성.
- **단서 검증**: LAN 신뢰 환경이므로 최소 검증(공백/길이)만. 강한 자연어 검증은 Out of Scope.
