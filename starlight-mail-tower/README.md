# 별빛 우편탑

두 명이 각자 노트북이나 브라우저로 접속해, 정비 로봇의 역할을 교대하며 5개 월드를 오르는 LAN 협동 게임이다. AI는 지원하지 않으며 정확히 두 명이 필요하다.

## 통합 런처에서 실행

프로젝트 루트에서 다음 명령을 실행한다.

```powershell
npm install
npm start
```

호스트와 같은 LAN에 연결된 두 기기에서 콘솔에 표시된 `http://<호스트-IP>:3000/` 주소를 연다. 각자 닉네임을 입력하고 **별빛 우편탑** 대기실에 들어간다. 먼저 접속한 p1 호스트가 레벨을 고른 뒤 두 명 모두 READY를 누른다.

## 단독 실행

게임 디렉터리에서 다음 명령을 실행한다.

```powershell
npm install
npm start
```

기본 주소는 `http://<호스트-IP>:3015/`다. 통합 런처의 대기실과 역할 배정까지 확인하려면 프로젝트 루트 실행을 사용한다.

## 조작

| 동작 | 키 |
|---|---|
| 좌우 이동 | `A` / `D` 또는 방향키 `←` / `→` |
| 점프 | `Space` |
| 고정·스위치 상호작용 | `E` 또는 `Enter` |

게임 화면의 언어·음소거·게임 선택 버튼은 Tab으로 이동하고 Enter 또는 Space로 실행할 수 있다.

## 화면 구조

게임 화면은 CSS Grid 3행 구조로 구성된다.

```
#game-shell (display: grid, grid-template-rows: 48px 1fr 52px)
  ├─ <header id="topbar">      ← HUD 패널(분류 데크·타이머·연결 상태) + 툴바(언어·음소거·게임 선택)
  ├─ <div id="play-viewport">   ← 캔버스(object-fit:contain, 16:9) + 오버레이(ready/result/reconnect 등)
  └─ <footer id="bottombar">    ← 내 상태(△) + 행동 안내 + 파트너 상태(○)
```

- 이전의 `#viewport-frame`은 제거되었다. 모든 HUD 패널과 툴바에서 `position:absolute`가 제거되어 메타 UI가 플레이 캔버스 영역을 침범하지 않는다.
- 캔버스는 `width:100%; height:100%; object-fit:contain`으로 play-viewport를 정확히 채우며, 내부 좌표계(`width="1280" height="720"`)는 불변이다.
- `#hud` id는 `client.js`의 `setBackgroundInert()`가 `'#hud'` 셀렉터를 사용하므로 보존되어 있다.
- 소형 뷰포트(max-width:1024px 또는 max-height:576px)에서는 topbar 40px / bottombar 44px으로 축소된다.

## 레벨

| 레벨 | 특징 |
|---|---|
| 별빛 우편탑 | 단자 고정과 스위치 교대를 익히는 입문 코스 |
| 구름 화물열차 | 이동 열차와 시간제 셔터를 건너는 교차 이동 코스 |
| 달빛 시계탑 | 회전 장치와 주기 발판의 타이밍 코스 |
| 폭풍 관측소 | 돌풍·상승 기류·동시 엄폐를 활용하는 코스 |
| 궤도 우편선 | 저중력과 합류 리프트를 결합한 종합 코스 |

모든 레벨은 8개 협동 모듈과 피날레로 구성된다. 카드의 예상 시간은 숙련자 6~10분, 첫 플레이 10~15분이며 실제 체감 시간은 두 기기 플레이테스트로 추가 조정할 수 있다.

## 협동 규칙

1. 역할 극성과 맞는 로봇이 단자 근처에서 상호작용을 유지해 장치를 고정한다.
2. 파트너가 열린 경로를 건너 반대편 스위치나 합류 지점에 도착한다.
3. 장치가 잠기면 고정 역할이 해제되고 다음 모듈에서는 역할을 교대한다.
4. 두 명이 함께 도착해야 체크포인트가 갱신된다. 한 명이 추락하면 둘 다 마지막 체크포인트로 복귀한다.
5. 마지막 좌우 스위치를 제한 시간 안에 함께 작동하면 우편 발사가 시작된다.

연결이 끊기면 게임은 일시 정지되고 15초 동안 재접속을 기다린다. 같은 브라우저로 돌아오면 역할과 진행 상태를 복원한다.

## 완주 후 흐름과 기록

완주하면 두 플레이어가 각각 **재도전**, **다음 레벨**, **레벨 선택** 중 하나를 고른다. 두 선택이 같을 때만 전환하며, 다르면 결과 화면에서 서로의 선택을 확인하고 다시 고를 수 있다. 다음 레벨은 다섯 번째 레벨 뒤에 첫 번째 레벨로 순환한다.

레벨별 최고 기록은 서버가 산정한 완주 시간 중 가장 빠른 값만 저장한다. 추락 수와 역할 교대 수는 결과 통계에 표시되지만 기록 순위에는 영향을 주지 않는다.

- 운영 기록: `data/records.json`
- 테스트 기록: `test-results/records.json`
- 손상된 기록 파일은 별도 파일로 격리되고 빈 기록으로 복구된다.
