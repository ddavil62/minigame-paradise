# 특수 발판 배치 기록

물리 발판 개편과 17개 레벨의 경로 재배치 결과를 기록한다.

## 배치 원칙

- 레벨마다 8개 구간의 좌우 진행 서명을 다르게 구성한다. 기본 레벨만 단순 좌우 교대를 유지한다.
- 같은 장치를 한 레벨에 3회 넘게 반복하지 않는다.
- 합체 리프트는 협동 테마가 분명한 7개 레벨에서만 사용한다.
- 명멸 발판(`cycle-platform`)은 먼저 안전하게 패턴을 관찰할 수 있는 발판을 두고, 서로 다른 위상으로 이어지는 구간에 배치한다.
- 신호 연결과 릴레이(`signal-link`, `relay`)는 협동 연결이 테마인 레벨에 한정한다.
- 저중력(`low-gravity`)은 진입 전에 일반 중력 점프를 한 번 보여 주고, 구역 안에서는 긴 체공을 이용하는 전용 경로를 만든다.
- 상승 기류(`updraft`)는 `zoneOffsetX`, `zoneOffsetY`, `zoneWidth`, `zoneHeight`, `liftAcceleration`, `maxLiftSpeed`, `lateralForce`로 레벨별 상승선을 조정한다.

## 신규 물리 장치 분포

- 고점프 발판: 구름 화물선, 화산 우체국, 열대우림 우편로, 하늘 정원
- 연결 배관: 달 시계탑, 사막 우편역, 마법 도서관
- 밀어내는 벽: 폭풍 정거장, 눈꽃 마을, 빙하 협곡, 자동화 공장, 고대 사원

## 도달 가능성 기준

- 모든 시작-경로-종료 발판 간 수평 간격과 상승 높이를 정적 검증한다.
- 배관 연결 대상, 움직이는 벽의 이동 범위, 특수 장치의 월드 경계를 검증한다.
- 17개 레벨 전부를 기본 타이밍과 장치 위상 지연 타이밍으로 실제 입력 기반 플레이스루한다.
- 체크포인트 이후 완료된 동적 발판은 안전 위치에 정박시켜 재시작 경로를 보장한다.
