# 별빛 우편탑 기획서

> 최종 업데이트: 2026-07-27

## 프로젝트 개요

별빛 우편탑은 두 플레이어가 역할을 나누어 장치와 체크포인트를 활성화하며 탑을 오르는 LAN 협동 플랫폼 게임이다. 서버가 이동·충돌·장치·체크포인트를 권위 판정하고, 브라우저는 서버 스냅샷을 바탕으로 Canvas 화면과 HUD를 표시한다.

## 기술 스택

| 항목 | 기술 |
|---|---|
| 서버 | Node.js, WebSocket (`ws`) |
| 클라이언트 | 바닐라 JavaScript, Canvas 2D |
| 시뮬레이션 | 서버 권위 30Hz 고정 스텝 |
| 상태 전송 | 약 15Hz 서버 스냅샷 |
| 테스트 | Node.js Test Runner, Playwright |

## 아키텍처

### 디렉토리 구조

```text
starlight-mail-tower/
  game/                 # 서버 권위 물리·장치·기록
  shared/               # 프로토콜·레벨 데이터
  public/js/            # 연결·입력·Canvas 렌더·보간
  public/css/           # 화면 스타일
  tests/                # 단위·통합·브라우저 회귀
  docs/                 # 현재 상태와 변경 이력
```

### 핵심 모듈

| 모듈 | 파일 | 역할 |
|---|---|---|
| 게임 서버 | `server.js` | 참가자·재접속·준비·스냅샷 전송과 게임 생명주기 |
| 서버 시뮬레이션 | `game/simulation.js` | 이동·충돌·협동 부스트·장치·체크포인트 권위 판정 |
| 레벨 카탈로그 | `shared/levels.js` | 17개 레벨의 지형·장치·동적 발판 정의 |
| 클라이언트 | `public/js/client.js` | WebSocket, 입력, 최신 권위 HUD·DOM 상태 |
| 보간 | `public/js/interpolation.js` | 스냅샷 수신 간격 추정과 렌더 전용 좌표 보간 |
| Canvas 렌더러 | `public/js/renderer.js` | 보간된 플레이어·발판·카메라와 최신 이산 상태 렌더 |

### 권위 상태와 렌더 상태

서버 스냅샷은 수신 즉시 HUD, 이벤트, 체크포인트와 진단 상태에 반영된다. Canvas는 이전·최신 스냅샷과 단조 수신 시각을 별도 버퍼에 보관하고, EWMA로 추정한 한 수신 구간만큼 지연된 시각에서 렌더 전용 복사본을 만든다.

P1/P2의 위치·속도, 동적 발판 위치와 회전 장치 각도는 같은 시간축에서 보간되며 카메라도 해당 플레이어 좌표를 추종한다. 레벨·페이즈·체크포인트 전환, 리스폰, 재접속, 긴 수신 공백, 중복·역행 tick, ID 누락과 큰 좌표 이동에서는 과거 경로를 사용하지 않고 최신 권위 좌표로 스냅한다. 외삽, 로컬 입력 예측과 클라이언트 충돌 판정은 하지 않는다.

## 기능 목록

| 기능 | 설명 | 상태 |
|---|---|---|
| 2인 협동 등반 | 역할별 결속·스위치·체크포인트와 협동 부스트 | 완료 |
| 17개 레벨 | 고유 테마, 장치와 동적 지형을 가진 레벨 카탈로그 | 완료 |
| 안전 리스폰 | 플레이어별 지지 발판 상면으로 체크포인트 복원 | 완료 |
| AI 파트너 | 런처 AI 채우기와 17개 레벨 협동 진행 | 완료 |
| 런처 준비 승계 | `lobbyReady` 진입은 READY 화면을 반복하지 않고 참가자·AI 연결 뒤 서버 START로 진행 | 완료 |
| 재접속 | 15초 유예와 역할·진행 상태 복구 | 완료 |
| 스냅샷 보간 | 약 15Hz 권위 좌표 사이를 rAF 렌더 좌표로 부드럽게 표시 | 완료 |

## 알려진 제약사항

- 서버 프로세스당 단일 참가자 슬롯 집합을 사용하므로 여러 독립 매치를 동시에 격리하지 않는다.
- 렌더 보간은 한 스냅샷 구간의 시각 지연을 사용하며 입력 예측·외삽은 지원하지 않는다.
- 플레이어와 발판의 순간이동 판정은 현재 이동 범위에 맞춘 고정 임계값을 사용하므로 향후 고속 레벨 추가 시 재검토가 필요하다.
- `tests/world-expansion.unit.spec.js`의 레벨 수 기대값 5는 현재 카탈로그 17과 불일치하는 기존 테스트 부채다.

## 향후 계획

- 고정된 레벨 수 기대값 테스트를 현재 카탈로그 기준으로 정리한다.
- 실제 두 기기 LAN 환경에서 장시간 체감 플레이테스트를 지속한다.
