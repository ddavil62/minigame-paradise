흔들기

흔들면 라운드 점수 ×2. 단 패배 시 손해도 ×2 (보수적이면 일반).

사통!

같은 월 카드 4장을 받았다 — 사통을 선언하겠는가?

사통 선언: 즉시 라운드 승리 + 7점 보너스. 포기하면 정상 진행.
