# 맞고 (Matgo) — LAN 1:1 대전

2인 고스톱(맞고)을 같은 LAN의 두 PC가 브라우저로 즐기는 Node.js 기반 게임.

## 실행

```bash
cd matgo
npm install
node server.js
```

- 기본 포트: **3003** (`--port 3004` 등으로 변경 가능)
- 호스트 PC: `http://localhost:3003`
- 친구 PC: 콘솔에 출력되는 LAN IP 주소 사용 (예: `http://192.168.x.x:3003`)
- 두 명이 접속하면 자동으로 게임 시작.

## 룰 요약

### 셋업
- 한국 표준 화투 48장 사용
- 각자 손패 10장, 바닥 8장, 더미 22장

### 턴 흐름
1. 손패에서 카드 1장 클릭
2. 바닥의 같은 월 카드와 자동 매칭 (1장이면 페어 가져감 / 2장이면 선택 / 3장이면 4장 스윕)
3. 더미에서 1장 뒤집어 추가 매칭
4. 점수 7점 이상이면 **고/스톱** 결정

### 특수 룰
- **쪽**: 손패 → 바닥 0매칭 후, 더미에서 같은 월이 나오면 → 둘 다 가져감 + 상대 피 1장
- **뻑**: 손패 매칭 직전에 더미 같은 월이 또 나옴 → 못 가져감 (3장 바닥 누적)
- **따닥**: 같은 턴에 같은 월 4장을 모두 가져감 → 상대 피 1장
- **자뻑**: 자기 뻑을 자기가 푸는 것 (일반 뻑 풀이와 동일)
- **흔들기**: 손패에 같은 월 3장 → 라운드 시작 시 선언, 점수 ×2
- **폭탄**: 손패 같은 월 4장 한번에 → 4장 점수판 + 상대 피 2장
- **광박**: 승자 광 3+ & 패자 광 0 → 점수 ×2
- **피박**: 패자 피 ≤6 → 점수 ×2
- **멍박**: 패자 끗 ≤6 → 점수 ×2
- **고박**: 고를 부른 사람이 결국 졌을 때 → 점수 ×2

### 점수 표
| 항목 | 점수 |
|---|---|
| 광 3장 | 3점 (비광 포함 시 2점) |
| 광 4장 | 4점 |
| 광 5장 | 15점 |
| 띠 5장 | 1점 (1장당 +1점) |
| 홍단/청단/초단 | 각 3점 |
| 비단(12월) | 별도 분류 — 띠 5장 모음에는 포함, 색깔 단 점수에서는 제외 |
| 끗 5장 | 1점 (1장당 +1점) |
| 고도리(2/4/8 매조·흑싸리·공산 끗) | 5점 |
| 피 10장 | 1점 (1장당 +1점, 쌍피는 2장) |
| 1고 | +1점 |
| 2고 | +2점 (누적) |
| 3고 이후 | ×2 누적 |

### 돈
- 시작 잔고 양쪽 10,000원
- 점당 100원 (헤더에서 변경 가능)
- 라운드 종료 시 (점수 × 점당) = 패자가 승자에게 지불

## 카드 표현

이미지 없이 텍스트+색깔로 카드 표시:
- **광** (금색)
- **비광** (보라)
- **홍단** (빨강) / **청단** (파랑) / **초단** (녹색) / **비단** (노랑 — 12월만, 별도 분류)
- **끗** (어두운 청회색) / **고도리** (보라)
- **피** (회색) / **쌍피** (갈색)
- 카드 우상단에 `N월` 표시

## 안정성

- 30초 heartbeat ping/pong
- 좀비 슬롯 자동 청소
- 자동 재접속 (1→2→4→8초 backoff)
- pagehide 시 즉시 WebSocket close

## 단순화된 룰
- 흔들기는 라운드 시작 시점 자동 검사 (이후 손패 시작 시점 흔들기 미지원)
- 폭탄 보너스는 간소화 (4장 점수판 + 상대 피 2장)
- 고박은 "고 부른 측이 결국 패배 시 점수 ×2"로 단순화
- 첫뻑/첫쪽 가산 변형 룰은 미적용
