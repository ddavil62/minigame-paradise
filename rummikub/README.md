# 루미큐브 (Rummikub) — 멀티플레이

타일 그룹/런을 만들어 손을 비우면 승리하는 1:1 두뇌 대결 게임. 미니게임 천국 9번째 종목.

> 친구는 같은 공유기에서도 `https://112.155.2.238`로 접속한다. 포트 3000과 개별 게임 포트는 내부·개발 전용이다.

## 실행

```powershell
# 단독 실행 (포트 3011, 충돌 시 자동 폴백)
cd C:\LazySlimeStudio\minigames\rummikub
node server.js --port 3011

# 통합 런처 내부 프로세스
cd C:\LazySlimeStudio\minigames
node launcher/server.js
# → 공개 운영은 start-public.ps1 실행 후 https://112.155.2.238 → "🀄 루미큐브" 카드 클릭
```

## 룰 요약

- **타일** 106장: 1~13 × 4색(빨/파/검/주) × 2세트 + 조커 2장
- **분배**: 각자 손 14장, 더미 78장
- **세트**:
  - 그룹: 같은 숫자, 다른 색 3~4장
  - 런: 같은 색, 연속 숫자 3장 이상 (1~13, wrap-around 없음)
- **첫 등판**: 본인이 처음 보드에 내는 모든 세트의 숫자 합 ≥ 30점
- **턴 종료 시**: 보드 전체가 valid. invalid면 모든 변경 롤백 + 더미 1장
- **변경 없이 종료**: 더미 1장 뽑기
- **승리**: 손 0장 즉시 승리

## 조작

- 본인 턴 시작 → 손 타일 클릭(선택, 강조)
- "＋ 새 세트" → 빈 세트 생성 → 보드의 빈 자리 클릭으로 삽입
- 또는 기존 세트의 슬롯 클릭으로 특정 위치에 삽입
- 보드 타일 클릭 → 선택 후 다른 슬롯 클릭으로 이동(등판 후 자유)
- "턴 종료" → 서버가 검증 후 commit 또는 롤백

## AI 봇

대기 화면의 "🤖 AI랑 시작" 버튼으로 즉시 시작 가능.
서버가 `bot.js`를 child_process로 spawn한다.

봇 휴리스틱:
- 첫 등판 미완: 손에서 30점 이상 가능한 그룹/런 조합 백트래킹 탐색
- 등판 후: 가능한 모든 그룹/런 자동 등판 (보드 재조합은 미지원, 단순화)
- 조커는 사용하지 않음
