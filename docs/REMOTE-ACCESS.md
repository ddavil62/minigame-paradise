# 외부 접속 운영 가이드

## 현재 구성

친구에게 전달할 주소는 `https://112.155.2.238`이다. 주소에 비밀번호를 넣지 않는다.

```text
친구 브라우저 → 공인 IP 443/Caddy HTTPS → 127.0.0.1:3000/통합 런처
                    │
                    └─ 최초 접속: 비밀번호 → 닉네임 → 로비
```

- Caddy만 공인 인터페이스의 TCP 80/443을 수신한다.
- Node 런처의 TCP 3000은 공인 인터페이스에서 Windows 방화벽으로 차단한다.
- 런처와 16종 게임의 HTTP 및 WebSocket은 같은 로그인 쿠키로 보호한다.
- 로그인 실패는 출발지별 5회 이후 15분 동안 차단한다.
- 비밀번호와 세션 값은 URL이나 로그에 남기지 않는다.

## 실행

기존 `node launcher/server.js` 창이 열려 있다면 먼저 `Ctrl+C`로 종료한다. 그 다음 프로젝트의
`start-public.bat`을 더블클릭하거나 PowerShell에서 실행한다.

```powershell
cd C:\antigravity\minigame-paradise
.\start-public.ps1
```

표시되는 프롬프트에 친구와 공유할 10자 이상의 비밀번호를 입력한다. 입력값은 화면에 보이지 않고
파일에도 저장되지 않는다. 다음 메시지가 나오면 접속 준비가 끝난 것이다.

```text
Minigame Paradise public server is ready.
Invite URL: https://112.155.2.238
```

이 창이 서버 프로세스와 HTTPS 프록시를 함께 관리하므로 플레이하는 동안 열어 둔다. 종료는 `Ctrl+C`다.

## 접속자 흐름

1. 처음 방문한 브라우저에는 접속 비밀번호 화면이 먼저 나온다.
2. 기본 선택된 "이 브라우저에서 30일간 기억"을 유지하면 같은 브라우저에서는 다음 방문부터 비밀번호를 건너뛴다.
3. 인증 뒤 기존 사용자는 저장된 닉네임이 있으면 바로 로비로 들어간다.
4. 로비의 "친구 초대 주소"에서 공인 HTTPS 주소를 복사해 전달할 수 있다.
5. 화면 우측 하단에서 버그리포트 버튼 왼쪽의 원형 친구 아이콘을 누르면 작은 "현재 접속 중" 팝업이 열린다. 기본은 최소화 상태이며 접속자의 닉네임과 로비·게임 대기실·플레이 중 상태를 확인할 수 있다.
6. 본인을 제외한 접속자를 누르면 1:1 채팅 화면이 열린다. Enter는 전송, Shift+Enter는 줄바꿈이며 읽지 않은 메시지는 친구 아이콘과 해당 사용자 행에 배지로 표시된다.

채팅은 인증된 WebSocket 안에서 송신자와 수신자 세션에만 전달한다. 메시지는 최대 500자이고 10초당 20개로 제한한다. 최근 대화는 서버 메모리에 대화별 최대 100건, 최대 24시간 보관되며 10분마다 전체 만료 기록을 정리한다. 서버 재시작 시에는 모두 초기화된다.

비밀번호를 바꾸어 재실행하면 이전 비밀번호로 만들어진 쿠키도 무효가 된다. 공용 PC에서는 기억하기를
해제하거나 브라우저 쿠키를 지운다.

## HTTPS 인증서와 IP 변경

Caddy는 Let's Encrypt의 공인 IP용 단기 인증서를 자동으로 발급하고 실행 중 갱신한다. 현재 주소의
프로덕션 인증서는 이미 발급 검증을 마쳤다. 공인 IP가 변경되면 스크립트가 새 주소를 자동 감지하고
새 인증서를 요청하므로 콘솔에 표시된 새 초대 주소를 사용한다. 인증서 발급을 위해 외부에서 TCP
80과 443에 접근할 수 있어야 한다.

## 방화벽 규칙

설치된 규칙은 다음 세 개다.

- `Minigame Paradise - Block public interface port 3000`
- `Minigame Paradise - Allow HTTPS proxy 80`
- `Minigame Paradise - Allow HTTPS proxy 443`

80/443 허용은 Caddy 실행 파일과 공인 인터페이스에만 적용된다. 3000 포트를 공유기나 Windows
방화벽에서 별도로 공개하지 않는다.

## 접속 정책

- 친구는 같은 공유기 안에서도 `https://112.155.2.238`로 접속한다.
- `http://{호스트IP}:3000`, `192.168.x.x:3000`, 개별 게임 포트를 친구에게 안내하지 않는다.
- `127.0.0.1:3000`은 Caddy의 내부 업스트림이며 서버 PC 점검용이다. 포트 3000의 인바운드 차단을 해제하거나 공유기에 포워딩하지 않는다.
- 공개 운영은 `start-public.ps1` 또는 `start-public.bat`만 사용한다. `npm start`와 개별 서버 실행은 개발·테스트 용도다.
