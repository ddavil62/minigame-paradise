# 사천성 배틀 기획서

> 최종 업데이트: 2026-07-23

## 프로젝트 개요

미니게임 천국에 통합된 LAN 1:1 사천성 아이템 대전이다. 두 플레이어는 동일한 12×8 초기 배치의 독립 보드에서 3분 동안 짝을 제거하며, 높은 빈도로 얻는 7종 아이템으로 상대를 방해하거나 자신을 보조한다.

## 기술 스택

| 항목 | 기술 |
|---|---|
| 서버 | Node.js, 바닐라 JavaScript ES modules |
| 통신 | HTTP, WebSocket (`ws`, noServer 통합) |
| 클라이언트 | HTML, CSS, 바닐라 JavaScript |
| 에셋 | GPT Image 2 기반 래스터, SVG 문양 합성, WebP 배경 |
| 테스트 | Node test runner, Playwright |

## 아키텍처

### 디렉토리 구조

```text
sichuan-battle/
  assets/       # 24종 타일과 배경, 생성 원본·검증표
  lib/          # 규칙, 경로, solver, 아이템, 경기 상태
  public/       # 대기·플레이·결과 UI와 ko/en 클라이언트
  scripts/      # 에셋 재생성·검증
  tests/        # 단위·프로토콜·2브라우저·시각 QA
  server.js     # 정적 파일과 서버 권위 WebSocket 앱
```

### 핵심 모듈

| 모듈 | 파일 | 역할 |
|---|---|---|
| 경기 상태 | `lib/game.js` | 플레이어별 보드·효과·타이머·결과·자동 셔플 관리 |
| 보드/해결기 | `lib/board.js`, `lib/solver.js` | 동일 시드 초기 배치와 완주 가능한 재배치 생성 |
| 경로 판정 | `lib/pathfinder.js` | 직선·1회·2회 꺾임과 외곽 연결 검증 |
| 아이템 | `lib/items.js` | 드롭, 인벤토리, 공격·보조 효과와 대응 규칙 |
| 서버 앱 | `server.js` | 런처 통합, 개인화 snapshot, 권위 검증, 복구·재대결 |
| 보드 UI | `public/js/board-view.js` | 타일·연결선·잠금·뒤집기·안개·힌트 렌더링 |
| 아이템 UI | `public/js/items-view.js` | 3슬롯, ko/en 설명, 효과 시간과 ARIA 렌더링 |

## 알려진 제약사항

- LAN 1:1·데스크톱 전용이며 AI, 3인 이상, 온라인 매치메이킹과 모바일 전용 UX를 지원하지 않는다.
- 인증, 인터넷 배포용 부정행위 방지, 영구 전적과 랭킹을 제공하지 않는다.
- 런타임은 생성된 PNG/WebP를 사용한다. 에셋 재생성에는 `scripts/build-assets.mjs`와 원본 파일이 필요하다.

## 향후 계획

- 실제 두 기기 LAN 환경에서 아이템 빈도와 공격 지속 시간 체감 플레이테스트
- 모바일 지원이 필요할 경우 보드·양쪽 패널을 별도 반응형 구조로 재설계
- 필요 시 랭킹·매치메이킹과 AI 연습 모드를 별도 범위로 검토
