# 하나비 (Hanabi) 🎇

2인 **완전 협력** 카드게임. 둘이 한 팀이 되어 5색 불꽃을 쏘아 올린다. 미니게임 천국 패키지의 7번째 종목.

> 친구는 같은 공유기에서도 `https://112.155.2.238`로 접속한다. 포트 3000과 개별 게임 포트는 내부·개발 전용이다.

## 어떤 게임인가

- 각자 **자기 손패를 볼 수 없다.** 상대 손패는 보이지만 내 손패는 가려져 있다.
- 직접 "네 카드는 3이야"라고 말할 수 없다. 제한된 **힌트 토큰**으로만 정보를 전달한다.
- 5색(흰·빨·파·초·노) 불꽃을 각 색마다 1→2→3→4→5 순서로 쌓아 **최대 25점**을 함께 만든다.
- 승패는 공동 점수로 결정된다. 함께 이기거나 함께 진다.

## 규칙 요약

자기 차례에 아래 **세 행동 중 하나**를 한다.

| 행동 | 효과 |
|------|------|
| **힌트 주기** | 정보 토큰 1개를 써서 상대 손패의 한 속성(색 또는 숫자)을 전부 알려준다. 토큰이 0이면 불가, 0장을 가리키는 힌트도 불가. |
| **카드 내기** | 손패 1장을 불꽃에 올린다. 다음 순번이면 성공, 아니면 폭탄 토큰 1개 소진. 5를 완성하면 정보 토큰 1개 회복(상한 8). |
| **카드 버리기** | 손패 1장을 버리고 정보 토큰 1개를 회복한다. 토큰이 8개로 가득 차면 버릴 수 없다. |

내기·버리기 후에는 덱에서 1장을 보충한다.

### 게임 종료 (3가지)

- **5색 전부 5까지 완성** → 25점 만점 승리("전설의 불꽃놀이!").
- **폭탄 토큰 3개 모두 소진** → 즉시 패배 (현재 점수 + "실패" 표기).
- **덱 소진** → 양쪽이 각 1턴씩 더 진행한 뒤 종료, 점수 집계.

### 점수 등급

| 점수 | 등급 |
|------|------|
| 0–5 | 처참함 |
| 6–10 | 아쉬움 |
| 11–15 | 무난함 |
| 16–20 | 훌륭함 |
| 21–24 | 경이로움 |
| 25 | 전설의 불꽃놀이! |

상세 룰은 `docs/RULEBOOK.md` 참조.

## 실행법

### 통합 런처로 실행 (권장)

```bash
cd C:\LazySlimeStudio\minigames
node launcher/server.js
```

친구 브라우저에서 `https://112.155.2.238` 접속 → 로비에서 **하나비** 카드 클릭. 두 명이 접속하면 게임이 자동 시작된다. (하나비는 AI 봇 미지원 — 2인 모드만)

### 단독 실행 (개발/테스트)

```bash
cd C:\LazySlimeStudio\minigames\hanabi
node server.js --port 3007
```

단독 실행은 서버 PC 개발·테스트에만 사용한다. 두 기기 친구 플레이는 공개 HTTPS 통합 런처를 사용한다.

## 기술

- Node.js (ESM) + `ws` (WebSocket), Express 미사용
- 바닐라 JS 클라이언트, 외부 이미지 에셋 없음 (5색 카드·토큰·불꽃 전부 CSS/HTML)
- 서버 권위 아키텍처 + 손패 가림 (서버가 본인 손패를 마스킹하여 전송)
