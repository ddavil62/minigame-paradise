# 윷놀이 (Yutnori) - LAN 1:1

> 친구와 같은 네트워크에서 즉시 즐기는 한국 전통 윷놀이 1:1 대전.

## 빠른 시작

### Windows (호스트)

1. **`start.bat` 더블클릭**
   - 첫 실행 시 자동으로 `npm install` 수행
   - Node.js 18+ 필요 ([nodejs.org](https://nodejs.org))
   - 새 콘솔 창에 LAN 접속 안내 박스가 뜸
2. 호스트 브라우저: 자동으로 `http://localhost:3000` 열림
3. **친구 PC**: 콘솔 박스의 `친구 PC 접속:` 라인의 IP 주소를 알려주거나, 호스트 화면의 "주소 복사" 버튼 사용
4. 양쪽 모두 **준비** 버튼 클릭 → 카운트다운 후 시작

### 종료

- 서버 콘솔 창에서 `Ctrl+C`, 또는 `stop.bat` 더블클릭

### 포트 충돌

- 기본 포트 `3000`. 다른 서비스(예: tetris-battle)가 점유 중이면 자동으로 `3001`, `3002`, ... `3010`까지 폴백.
- 실제 사용 중인 포트는 콘솔 박스에 표시됨.

## 게임 규칙 요약 (한국 표준 윷놀이)

### 보드

- 외곽 사각형 20칸 + 두 대각 지름길 + 중앙(방) = 약 29칸
- **시작점**(좌하) → 시계 방향 → 다시 시작점 통과 = 완주
- **모서리에 정확히 멈추면** 다음 이동부터 지름길 사용
  - 좌상(5) → 지름길A → 중앙 → 우하(15)
  - 우상(10) → 지름길B → 중앙 → 좌하(시작점=완주)
- **중앙(방)** 도달 시 두 출구 중 선택 (모달 표시)

### 윷가락

평평한 면이 위로 보이는 개수가 곧 이동 칸 수 (모만 예외).

| 결과 | 평평면 / 둥근면 | 이동 |
|------|-----------------|------|
| 도   | 1 / 3           | 1칸  |
| 개   | 2 / 2           | 2칸  |
| 걸   | 3 / 1           | 3칸  |
| 윷   | 4 / 0           | 4칸 + 한 번 더! |
| 모   | 0 / 4           | 5칸 + 한 번 더! |
| 백도 | 1 / 3 (그 1개 평평면이 마크 가락) | -1칸 (뒤로) |

- 윷/모면 보너스 턴
- **잡기**(같은 칸 상대 말): 상대 말 출발점으로 + 보너스 턴
- **업기**(같은 칸 자기 말): 다음 이동 시 함께 이동. 업힌 묶음이 잡히면 전부 출발점으로
- **백도(-1칸)**: 4개 가락 중 빨간 X 표식이 있는 가락 1개만 뒤집혀 있을 때 발동. 출발한 말만 1칸 뒤로. HOME 말엔 사용 불가(자동 폐기). 보너스 턴 없음.

### 승리

- 자기 말 4개 모두 완주

## 조작

- **윷 던지기** 버튼 → 결과가 좌측 "남은 결과" 큐에 추가됨
- 남은 결과 칩 클릭 → 사용할 결과 선택 (강조됨)
- 보드의 내 말 클릭 → 해당 말 이동
- HOME(시작 전) 말 출발: 보드 좌하(P1)/우상(P2) HOME 영역 클릭 또는 빈 영역 클릭으로 자동 선택
- 중앙 도착 시: 모달의 "↖ 위쪽 출구 / ↙ 아래쪽 출구" 선택
- 게임 종료 시: **재대결** 버튼 (양쪽 모두 누르면 새 게임)

## 아키텍처

**서버 권위 (Server Authoritative)**:
- 윷가락 던지기 결과 = 서버에서 결정 (클라 부정 방지)
- 말 이동/잡기/업기 판정 = 서버
- 매 액션 후 `STATE` 메시지로 전체 게임 상태 broadcast
- 클라이언트는 입력 + 렌더링만 담당

## 기술 스택

- Node.js 18+ (ESM), Express 4, ws 8
- 바닐라 JS (프레임워크 0), HTML5 Canvas
- 외부 에셋 0 (Canvas/CSS로 표현)
- 한국어 UI + 한국어 주석/JSDoc

## 테스트

별도 포트(3088 권장)로 서버를 띄운 뒤 smoke 슈트 실행:

```powershell
cd C:\LazySlimeStudio\minigames\yutnori
# 터미널 1
node server.js --port 3088
# 터미널 2
node tests/smoke.test.js --port 3088
```

기대 출력: `PASS: 18, FAIL: 0`

## 트러블슈팅

- **친구 PC에서 접속 안 됨**: Windows Defender 방화벽에서 Node.js의 "개인 네트워크" 액세스 허용 필요. 같은 Wi-Fi에 있는지 확인.
- **포트 3000 사용 중**: 자동으로 3001~3010 폴백. 콘솔 박스의 실제 포트 확인.
- **재대결 후 화면 이상**: 새로고침(F5) → 자동 재입장.
