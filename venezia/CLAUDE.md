# Venezia (베네치아 타이핑 배틀) — 프로젝트별 작업 컨벤션

> LAN 1:1 한국어 타이핑 대전. Node.js + 바닐라 JS + Canvas. 미니게임 천국 14번째 종목 (포트 3017).

## 정체성

- **목적**: 한메/한컴 타자교사의 고전 2인 대전 '베네치아'를 LAN 멀티플레이로 재현.
- **기술**: Node 18+ (ESM), 순수 `node:http` + `ws` 8, 바닐라 JS + HTML5 Canvas.
- **외부 에셋**: 0. UI는 CSS + Canvas 합성만.

## 게임 룰

| 항목 | 규칙 |
|---|---|
| 플레이어 | 2인 (LAN 1:1) |
| 정답 | 단어 제거·콤보·아이템 드랍만 처리. 상대 HP 피해, `attackDamage`, `HIT` 없음 |
| HP·종료 | HP 100과 회복·`hp_zero` 호환 구조는 유지하지만 정상 플레이의 감소 경로와 자동 종료 규칙은 없음 |
| 아이템 조작 | 입력창 포커스 중에도 단독 숫자키·숫자패드 `1/2/3`으로 슬롯 사용. Alt 조합은 사용하지 않음 |
| 급류 | 내부 호환 ID `item_freeze`를 유지하며, 사용자 효과는 4초간 상대 단어 낙하·서버 만료 2배 |
| 단어 스폰 | 1.5초마다, 동시 최대 5개 |
| 난이도 전환 | 0~29초: 초급, 30~59초: 초중급 혼합, 60초+: 전 단계 |

> 알려진 위험: 양쪽이 기권하거나 이탈하지 않으면 경기가 자동 종료되지 않을 수 있으며, 피해원이 없어 회복 아이템은 정상 플레이에서 실질 효과가 없다.

## 테스트 실행법

```bash
# 단독 실행
node venezia/server.js --port 3017
```

## 포트

- 단독 실행: 3017 (충돌 시 +1 폴백)
- 통합 런처: 3000 (/venezia/ 경로)
