# 요트 다이스 — 우드 테마 적용 가이드 (방향 B: 파치먼트 & 우드)

이 폴더는 형 프로젝트의 `public/` 를 그대로 대체하는 **드롭인 교체본**이에요.
**게임 로직 · 네트워크 · 서버 · 봇은 한 줄도 안 바뀝니다.** 외형(뷰)만 우드 테마로 교체.

---

## 1. 실제로 바뀐 파일은 4개

| 파일 | 변경 내용 |
|---|---|
| `index.html` | 마크업 구조 + 클래스 정리, `<body class="theme-wood">`, 폰트 링크, **점수표 열 순서 P1·카테고리·P2 → 카테고리·P1·P2**, 게임 화면 2단 레이아웃. **`main.js`가 쓰는 element ID는 전부 그대로 유지.** |
| `css/style.css` | 전체를 우드 테마로 교체 (대기/게임/점수표/결과/토스트 + 주사위 컵 애니메이션) |
| `js/dice.js` | Canvas pip → **CSS pip** 주사위. 굴릴 때 **가죽 주사위 컵 흔들기 애니메이션** 추가 (다이스 값 변화를 스스로 감지 → `main.js` 수정 불필요). 함수 시그니처 동일. |
| `js/scoreboard.js` | 점수표 열 순서만 **카테고리 → P1 → P2** 로 재배치. 클래스명·로직 동일. |

## 2. 그대로 둔 파일 (참고용으로 폴더에 포함, 형 원본과 100% 동일)

`js/main.js`, `js/network.js`, `js/game.js`, `js/ui.js`
→ 덮어써도 동일하므로 안전. `server.js`, `bot.js`, `package.json` 등 `public/` 바깥은 **건드릴 필요 없음.**

---

## 3. 적용 방법

```bash
# 1) 혹시 모르니 기존 public 백업
cp -r public public_backup

# 2) 이 폴더(port) 안의 파일들을 public/ 에 덮어쓰기
#    index.html, css/style.css, js/dice.js, js/scoreboard.js (+ 원본 동일 파일들)
cp -r port/* public/

# 3) 서버 재시작 후 접속 — 끝.
```

또는 4개 파일만 골라서 덮어써도 됩니다: `index.html`, `css/style.css`, `js/dice.js`, `js/scoreboard.js`.

---

## 4. 디자인 변경 요약

- **2단 레이아웃**: 왼쪽 = 가죽 다이스 트레이, 오른쪽 = 양피지 점수표.
- **두 플레이어 점수 인접 비교**: 카테고리 옆에 P1·P2 칸이 나란히.
- **주사위 컵 연출**: 굴리면 컵이 올라와 촤르륵 흔들리고 → 기울여 쏟아지며 새 눈이 통통 착지. KEEP한 주사위는 컵 옆에 그대로 남음.
- **현재 턴 강조**, 미리보기 점수, 상단/추가 야츠 보너스 표시 모두 유지.

## 5. 주사위 컵 애니메이션 타이밍

- 흔들기+쏟아짐 총 길이는 `css/style.css` 의 `@keyframes cup-shake` (1초)와
  `js/dice.js` 상단의 `ROLL_MS = 1000` 이 **짝**을 이룹니다. 속도를 바꾸려면 둘 다 같이 조정하세요.
- 더 빠르게: 둘 다 700~800으로. 더 느긋하게: 1200 등.

## 6. ⚠️ 폰트 (LAN/오프라인 주의)

`index.html` 은 Google Fonts(**Jua**, **Gowun Dodum**)를 CDN으로 불러와요.
**인터넷이 없는 LAN 환경**에서는 폰트가 안 받아져 시스템 기본 폰트로 폴백됩니다(레이아웃은 정상, 느낌만 살짝 밋밋).
오프라인에서도 똑같이 보이게 하려면 폰트를 **로컬에 번들**해야 해요 — 필요하면 woff2 파일 + `@font-face` 세트로 만들어 드릴게요.
