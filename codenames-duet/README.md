# Codenames Duet — 1:1 협력

두 PC가 브라우저로 접속해 즐기는 **코드네임 듀엣** 협력 플레이.

> 실제 친구 접속은 통합 런처의 `https://112.155.2.238`만 사용한다. 같은 공유기에서도 호스트 IP나 개별 포트로 직접 접속하지 않는다. 아래 단독 서버 실행은 개발·테스트 전용이다.

## 실행

```bash
cd codenames-duet
npm install
node server.js
```

단독 서버에는 서버 PC의 브라우저로만 접속한다. 친구 플레이는 프로젝트 루트의 공개 HTTPS 런처를 사용한다.

## 게임 규칙 요약

- 5x5 = 25장의 단어 카드. 양 플레이어는 같은 단어를 보지만, **각자의 키 카드 색상은 다르다**.
- 각 카드 모서리 작은 점이 **내 시점에서의 색상** (초록=아군, 황갈=중립, 검정=암살자).
- 차례 플레이어가 단서(단어 + 숫자 1~9)를 입력하면 상대가 그 숫자만큼 카드를 추측한다.
- 추측 결과는 단서를 **준 사람의 시점 색상**으로 공개된다:
  - 그린: 정답, 계속 추측 가능 (남은 추측 횟수 -1)
  - 중립: 턴 종료, **미션 토큰 -1**
  - 암살자: 즉시 패배
- 패스해도 미션 토큰 -1.
- **승리**: 양쪽 모두 자기 시점 그린 9개를 발견했을 때.
- **패배**: 암살자 클릭, 또는 미션 토큰이 0이 되었을 때.

## 복기 모드 (2026-06-09 추가)

게임이 끝나면 결과 모달에 **"🔍 복기 보기"** 버튼이 같이 뜬다. 누르면 모달이 닫히고
보드 25칸이 **양쪽 시점 키 카드 전체 공개** 상태로 전환된다 (좌상단=내 시점, 우하단=상대 시점).
친구와 천천히 복기·잡담하다가 상단 배너의 **🔄 새 게임 / ← 다른 종목** 버튼을 직접 눌러야 다음으로 넘어간다.
"결과 다시 보기" 버튼으로 복기 모드를 닫고 결과 모달을 재오픈할 수도 있다.
복기 중에는 카드 클릭과 단서 입력이 모두 비활성화된다.

## 기술 스택

- Node.js 18+ (ESM)
- 의존성: `ws` (WebSocket)만 사용
- 클라이언트: 바닐라 JavaScript + HTML5

## 디렉토리 구조

```
codenames-duet/
├── server.js       # HTTP + WebSocket 서버
├── game.js         # 게임 상태/규칙
├── words.js        # 한국어 단어팩 (약 380개)
├── package.json
└── public/
    ├── index.html
    ├── style.css
    └── client.js
```
