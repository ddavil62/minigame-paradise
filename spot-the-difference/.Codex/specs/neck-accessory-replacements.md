# 동물 목 액세서리 차이점 교체

목표: 반복되는 목걸이·방울 차이점을 각 장면의 고유 오브젝트로 교체한다. 각 단계는 이미지 A/B, 판정 영역, 후보 메타데이터, 공개 카탈로그를 함께 갱신하고 기존 생성 원본은 보존한다.

1. [완료] `moonlit-greenhouse-01` 달빛 온실 — 고양이 목걸이 → 오른쪽 칼라꽃 색
2. [완료] `autumn-alchemy-kitchen-01` 단풍빛 연금술 부엌 — 고양이의 파란 목걸이 → 고양이 방석의 단풍잎 자수
3. [완료] `retro-comic-robot-garage-01` 팝! 로봇 정비소 — 고양이의 초록색 목걸이 → 오른쪽 파이프의 레버형 밸브
4. [완료] `retro-comic-monster-tv-studio-03` 팝! 괴물 TV 스튜디오 — 고양이의 노란 목걸이 → 꺼진 오른쪽 스튜디오 조명
5. [완료] `retro-comic-alien-laundromat-04` 팝! 외계인 세탁소 — 우주 강아지의 노란 목걸이 → 사라진 노란 수건 더미
6. [완료] `japanese-comics-manga-studio-01` 빗소리 만화 작업실 — 고양이 목걸이 방울 → 청록색으로 바뀐 긴 그림 자
7. [완료] `japanese-comics-glasshouse-atelier-05` 봄빛 유리온실 화실 — 고양이 방울 → 사라진 화구 바구니 손잡이

유지: `moonlit-clockwork-shop-01`의 고양이 방울은 시계공방 테마와 맞아 대표 사례로 남긴다.
