# 마작 — 프로젝트 현황

## 개요

4인 일본식 리치마작. 서버 권위(`lib/game.js`)이며 사람 1~4명 + 서버 관리형 AI로 구성한다. 디자인은 목업 시안 A(클래식 자동탁)에 흰색 패 앞면을 적용했다. 규칙 결정(2026-10-28): 일본 리치마작, 동풍전 기본(반장전 선택), 초보 도우미는 옵션.

## 구성

| 영역 | 파일 | 역할 |
|---|---|---|
| 규칙 엔진 | `lib/tiles.js`, `lib/agari.js`, `lib/game.js` | 패·역·부수·점수·국 진행 |
| AI/도우미 | `lib/ai.js`, `lib/hints.js` | 3단계 AI, 향청수·대기패·안전패 힌트 |
| 서버 | `server.js` | 룸·좌석(사람 2명은 동·서)·타이머·자동 진행·재접속 |
| 클라이언트 | `public/` | 1200×760 무대 비율 축소, 방 설정·대국·결과·종료 화면 |

## 상태

| 기능 | 상태 |
|---|---|
| 리치마작 전체 룰(리치·울기·깡·후리텐·유국·점수) | 완료 |
| 동풍전/반장전, 서입, 도비, 아가리야메 | 완료 |
| AI 쉬움/보통/어려움 | 완료 |
| 친구 1~3명 + AI, 재접속, 자동 진행 | 완료 |
| 초보 도우미, 한글 패 이름 | 완료 |
| 파오, 우마·오카, 관전, 키아트 이미지 | 미구현 |
| 모바일 세로 화면 | 가로 모드 안내만 제공 |

## 알려진 제약

- 런처 대기실에서 전원이 준비하면 즉시 게임 서버로 넘어간다. 사람은 게임 서버의 방 설정 화면에서 이어서 모이며, 대국 중에는 새로 입장할 수 없다.
- 게임 서버는 프로세스당 방이 하나다.
- AI는 다마텐(역 있는 무리치 화료)과 복잡한 수비 읽기를 하지 않는다.
