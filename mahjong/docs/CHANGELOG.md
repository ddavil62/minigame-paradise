# Changelog

## [2026-10-28] - 마작 방장·패 이동 연출·이펙트

- 런처 대기실 호스트가 게임 방 방장이 되도록 고쳤다. 리디렉션 후 먼저 접속한 사람이 방장이 되던 문제를 `role=p1`로 바로잡았다(최초 1회만 인정).
- 패가 순간이동하던 것을 손(상대는 패 더미)에서 연못으로 호를 그리며 날아가 착지하도록 바꿨다. 착지 때 충격파·먼지·화면 흔들림과 효과음이 붙는다.
- 이펙트를 추가했다: 국 시작 배너와 손패 돌리기, 뽑은 패·도라 공개 연출, 퐁/치/깡 팝업, 리치 배너·붉은 플래시·점봉, 론/쯔모 배너·색종이, 유국 배너, 결과창 순차 등장과 점수 카운트업.
- 연출 레이어(`#fx`)를 재렌더와 분리해 기존 콜아웃이 다음 STATE에 지워지던 문제도 해결했다.
- 두 가상 플레이어 시연 영상 녹화 스크립트(`tests/record-demo.mjs`)를 추가했다.

## [2026-10-28] - 마작 신규 추가

- 4인 일본식 리치마작을 추가했다. 서버 권위 규칙 엔진(역 40여 종, 부수·점수, 후리텐, 리치·일발, 깡·창깡, 유국 6종과 유국만관, 도비·아가리야메·서입)과 서버 관리형 AI 3단계를 포함한다.
- 사람 1~4명이 방 설정 화면에서 모이고 빈자리는 AI가 채운다. 두 사람이면 마주 보는 자리(동·서)에 앉는다. 재접속, 시간 초과·접속 끊김 자동 진행을 지원한다.
- 클래식 자동탁(흰색 패) 화면, 초보 도우미(향청수·대기패·안전패·추천 버림), 한글 패 이름, 효과음을 제공한다.
- 런처 카탈로그(`games.json`)와 `GAME_APPS`, `GAME_MANAGED_AI_IDS`에 등록했다.
- 규칙·AI·서버 통합·UI 회귀 테스트를 추가했다.
