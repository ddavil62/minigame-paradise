# 마작 (일본식 리치마작)

녹색 자동탁에서 즐기는 4인 리치마작. 친구와 마주 앉고 빈자리는 AI가 채운다.

## 플레이 방법

1. 미니게임 천국 포털에서 **마작**을 고르고 `AI로 채우기`(혼자) 또는 친구가 들어온 뒤 `준비`를 누른다.
2. 방 설정 화면에서 대국 길이(동풍전/반장전), AI 난이도, 적도라·쿠이탕을 고르고 **대국 시작**을 누른다(방장만 변경 가능).
3. 내 차례에 패를 한 번 누르면 들어 올려지고, 같은 패를 다시 누르면 버려진다. 리치·쯔모·깡은 오른쪽 아래 버튼으로 선언한다.
4. 상대가 버린 패로 론·퐁·치·깡을 할 수 있으면 버튼이 나타난다(10초 안에 선택, 지나가면 자동 패스).

### 초보 도우미 (상단 `도우미` / `한글 패 이름`)

- 텐파이까지 남은 향청수, 추천 버림, 대기패와 남은 장수를 알려 준다.
- 리치한 상대가 이미 버린 패(현물)에 `안전` 표시를 붙인다.
- 패 아래에 `1만·5통·3삭` 같은 한글 이름을 표시한다.
- 두 설정은 이 브라우저에 저장되며 본인에게만 적용된다.

## 규칙 요약

| 항목 | 내용 |
|---|---|
| 패 | 136장, 적도라(5만·5통·5삭) 선택 |
| 시작 점수 | 25,000점 (30,000점 이상 1위가 있으면 종료) |
| 동풍전 | 동 1~4국 (약 15~25분) |
| 반장전 | 동 + 남 1~4국 (약 40~60분) |
| 종료 | 0점 미만(도비), 올라스 친 1위 아가리야메, 서입/남입 최대 4국 |
| 울기 | 퐁·치·대명깡, 식스왑(쿠이카에) 금지, 쿠이탕 선택 |
| 유국 | 산이 다하면 텐파이료(3,000점), 구종구패·사풍연타·사가립직·사깡산료·삼가화, 유국만관 |

자세한 역 목록과 구현 범위는 [CLAUDE.md](CLAUDE.md)를 본다.

## 실행

통합 런처(`node launcher/server.js`)에서 `/mahjong/`로 서빙된다. 단독 실행:

```powershell
cd C:\antigravity\minigame-paradise\mahjong
node server.js --port 3021
```

친구 접속은 항상 공인 IP HTTPS 주소를 사용한다(루트 `CLAUDE.md`의 접속 정책 참고).
