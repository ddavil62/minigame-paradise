# 다빈치 코드 (Da Vinci Code / 알고리즘) — LAN 1:1

같은 LAN의 두 PC가 브라우저로 접속해 2인 대전을 즐기는 다빈치 코드(알고리즘) 구현체.

## 실행 방법

```bash
cd C:\LazySlimeStudio\minigames\davinci-code
npm install   # 최초 1회
node server.js
```

기동 후 콘솔에 LAN IP가 표시된다.

- **호스트 PC**: `http://localhost:3002`
- **친구 PC**: `http://{호스트IP}:3002` (같은 Wi-Fi/유선 LAN)

> 코드네임 듀엣(포트 3001)과 동시에 띄울 수 있다. 두 게임이 서로 간섭하지 않는다.

처음 실행 시 Windows Defender 방화벽 팝업이 뜨면 "개인 네트워크" 허용.

## 룰 요약 (2인 단순화 버전)

### 카드 구성
- 흑색 0~11 (12장) + 백색 0~11 (12장) = 24장
- 손에서 자동으로 **숫자 오름차순** 정렬, 동률이면 **흑이 백보다 앞**

### 진행
1. 각자 4장씩 비공개로 손에. 나머지는 덱.
2. 자기 턴:
   - 덱에서 1장 뽑음 (본인만 봄). 덱이 비었으면 생략.
   - 상대 손의 카드 1장을 클릭으로 지목 + 숫자(0~11) 추측
3. **맞히면**: 상대 카드가 공개되고, 본인이 **"계속 추측 / 멈춤"** 선택
   - **멈춤**: 뽑은 카드를 비공개로 자기 손에 추가, 턴 종료
   - **계속**: 다시 추측 단계로 (뽑은 카드는 그대로 유지)
4. **틀리면**: 뽑은 카드가 공개로 자기 손에 추가, 턴 종료
   - 덱이 비어 못 뽑은 상태에서 틀리면: 자기 손에서 미공개 1장을 골라 공개해야 함
5. **승리**: 상대의 모든 카드가 공개되면 승리

### 범위 (이번 구현 제외)
- 조커 카드 X (단순화)
- 3~4인 X (2인 전용)

## 기술 스택
- Node.js (>=18, ESM)
- 의존성: `ws`만
- 바닐라 JS + HTML + CSS

## 안정성
- WebSocket 30초 heartbeat (좀비 연결 자동 청소)
- 클라이언트 자동 재연결 (backoff 1→2→4→8s)
- pagehide 시 즉시 close → 좀비 슬롯 방지
- 정원 2명 초과 거절

## 트러블슈팅

| 증상 | 원인 / 해결 |
|---|---|
| 친구 PC 접속 불가 | 같은 LAN인지, 방화벽 "개인 네트워크" 허용했는지 확인 |
| 포트 충돌 | `node server.js --port 3003` 으로 다른 포트 사용 |
| 카드 숫자 누출 의심 | 상대 미공개 카드의 value는 서버에서 절대 보내지 않음 (game.js `snapshotForPlayer` 검증) |
