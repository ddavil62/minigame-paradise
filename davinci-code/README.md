# 다빈치 코드 플러스 (Da Vinci Code+) — LAN 1:1

같은 LAN의 두 PC가 브라우저로 접속해 2인 대전을 즐기는 다빈치 코드 플러스(3색) 구현체.

## 실행 방법

```bash
cd C:\antigravity\minigame-paradise\davinci-code
npm install   # 최초 1회
node server.js
```

기동 후 콘솔에 LAN IP가 표시된다.

- **호스트 PC**: `http://localhost:3002`
- **친구 PC**: `http://{호스트IP}:3002` (같은 Wi-Fi/유선 LAN)

> 미니게임 천국 통합 런처(포트 3000)에서도 `/davinci-code/` 경로로 접속 가능하다.

처음 실행 시 Windows Defender 방화벽 팝업이 뜨면 "개인 네트워크" 허용.

## 룰 요약 (다빈치 코드 플러스 2인 버전)

### 카드 구성
- 빨강(Red) 0~11 (12장) + 조커 1장 = 13장
- 노랑(Yellow) 0~11 (12장) + 조커 1장 = 13장
- 파랑(Blue) 0~11 (12장) + 조커 1장 = 13장
- **총 39장**
- 손에서 자동으로 **숫자 오름차순** 정렬, 동률이면 **빨강 < 노랑 < 파랑** 순

### 진행

#### 1. 조커 배치 페이즈 (게임 시작 전)
1. 각자 4장씩 비공개로 배분 (조커 1장 별도 보관)
2. 자신의 손패 사이에서 조커를 원하는 위치에 배치
3. 양쪽 모두 배치 완료하면 게임 시작
- 배치 후 조커 위치는 변경 불가
- 상대에게는 색상만 보임 (숫자 "?" 표시)

#### 2. 게임 진행
1. 덱에서 1장 뽑음 (본인만 봄). 덱이 비었으면 생략.
2. 상대 손의 카드 1장을 클릭으로 지목
   - **숫자 추측**: 0~11 입력 후 "추측" 버튼
   - **조커 추측**: "조커?" 버튼
3. **맞히면**: 상대 카드가 공개되고 **"계속 추측 / 멈춤"** 선택
   - **멈춤**: 뽑은 카드를 비공개로 손에 추가, 턴 종료
   - **계속**: 다시 추측 단계로
4. **틀리면**: 뽑은 카드가 공개로 손에 추가, 턴 종료
   - 덱이 비어 못 뽑은 상태에서 틀리면: 내 미공개 카드 1장을 직접 공개해야 함
5. **승리**: 상대의 모든 카드가 공개되면 승리

### 조커 카드 규칙
- 본인에게는 `-`로 표시 (조커임을 알고 있음)
- 상대에게는 색상만 보이고 숫자는 `?`로 표시
- 상대가 조커를 추측하려면 "조커?" 버튼을 눌러야 정답 인정
- 조커가 공개되면 메모판의 해당 색 조커 타일이 dim 처리됨

### 범위 (이번 구현 제외)
- 보너스 카드 룰 없음
- 3~4인 없음 (2인 전용)

## 기술 스택
- Node.js (>=18, ESM)
- 의존성: `ws`, `express`
- 바닐라 JS + HTML + CSS

## 안정성
- WebSocket 30초 heartbeat (좀비 연결 자동 청소)
- 클라이언트 자동 재연결 (backoff 1→2→4→8s)
- pagehide 시 즉시 close → 좀비 슬롯 방지
- 정원 2명 초과 거절
- 서버 권위 게임 상태 (클라이언트는 입력+스냅샷만)

## 트러블슈팅

| 증상 | 원인 / 해결 |
|---|---|
| 친구 PC 접속 불가 | 같은 LAN인지, 방화벽 "개인 네트워크" 허용했는지 확인 |
| 포트 충돌 | `SERVER_PORT=3003 node server.js` 로 다른 포트 사용 |
| 카드 숫자 누출 의심 | 상대 미공개 카드의 value는 서버에서 절대 보내지 않음 (`game.js snapshotForPlayer` 검증) |
| 조커 배치 버튼 안 뜸 | 게임 시작 직후 조커 배치 페이즈에서만 표시됨. 새 게임 시작 후 재시도 |
