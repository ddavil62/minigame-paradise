# Tetris Battle 알려진 문제

현재 코드나 테스트에서 확인된 미해결 문제만 기록한다. 해결된 항목은 제거하고 변경 이력은 `CHANGELOG.md`에 남긴다.

## `phase3-4-qa-edge` Q7b 오검출

- 증상: `printBanner`가 유니코드 박스 문자를 사용하지 않는지 검사하는 테스트가 실패할 수 있다.
- 원인: 함수 추출 정규식이 실제 함수 경계를 넘어 뒤의 섹션 구분 주석까지 포함한다.
- 사용자 영향: 실제 배너 출력은 ASCII라 기능 영향은 없다.
- 해결 방향: 정규식을 `printBanner` 함수 본문 경계로 한정한다.

## `ai-mode-e2e.spec.js` 환경 의존 실패

- 증상: Playwright self-host 환경에서 페이지 로드 직후 WS 연결이 닫히며 일부 AI 진입 테스트가 실패할 수 있다.
- 범위: 일반 서버 실행과 하트비트 로직의 기능 실패로 단정하지 않는다.
- 확인 방법: 동일 커밋에서 단독 서버와 `bot-smoke.test.js`를 함께 실행해 환경 문제와 실제 회귀를 구분한다.
- 해결 방향: self-host 서버 준비 신호와 페이지의 JOIN 타이밍을 결정적으로 만든다.
